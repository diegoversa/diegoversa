## 🧠 Deep dive: Bot de Apuestas Deportivas

> El proyecto más complejo técnicamente — combina OCR, IA y automatización end-to-end.

```
📸 Input:  Foto de ticket (Bet365, Winamax, Betfair, Codere...)
    ↓
🔍 OCR:    Extracción de texto con preprocesado de imagen
    ↓
🤖 IA:     Interpretación de formato variable, detección de campos
    ↓
📊 Output: Cuota · Importe · Estado · Ganancia → Google Sheets
    ↓
📱 UI:     Bot de Telegram para gestión y consultas desde el móvil
```
